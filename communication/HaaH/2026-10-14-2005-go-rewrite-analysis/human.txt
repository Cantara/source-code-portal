PROPOSAL: a small gate between milestones, rest stays autonomous
- One "done when" line per milestone, written by you before it starts.
- A live read-only run against the Cantara org with the converted config.json,
  producing a membership/README/badge diff against the Java portal.
- Always stop before: dropping a Java feature, tag/release/publish/delete,
  config or schema changes after the first live run.
- Milestone close also writes docs/MIGRATION.md and files deferred items as
  issues.

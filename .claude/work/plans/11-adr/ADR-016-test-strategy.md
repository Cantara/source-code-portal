# ADR-016: Test strategy

Status: Accepted. Date: 2026-10-14. Refines 04 D-10 (A-09).

## Context
Tests that assert nothing, depend on the network or exercise code that does not ship give false confidence, so every test must assert, run offline and exercise the shipping code (GR-43). D-10 asks for fake GitHub, golden files, `-race`, fuzzing, goleak, an import-boundary test and an end-to-end smoke test. D-10 (`-race`) and D-11 (`CGO_ENABLED=0`) conflict because the race detector needs cgo.

## Decision
- Pyramid: unit and table tests; consumer fakes in `_test.go`; `store/memory`; `storetest` conformance on both SQLite drivers; engine/planner/scheduler/lifecycle/webhook tests inside `testing/synctest` bubbles with `httptest.NewTestServer`; SQLite tests outside bubbles.
- `github/githubtest`: fake GitHub with recorded fixtures and fault injection (403/429/secondary limits, 5xx, truncated trees, token expiry); drives adapter tests, `cmd/scp` e2e (`run()` booted until `/readyz`), `cmd/fakegithub` for dev and Playwright.
- Golden files for HTML, SVG (parsed with `encoding/xml`), Markdown, config, CSP strings; a 36-payload sanitiser corpus plus differential allow-list walk; native fuzzing for matchers, config, renderer, descriptor and every manifests parser (seven shared invariants); `goleak` in `TestMain`; route table verification and typed-route e2e crawl; anonymous-visibility enumeration over every route; budget arithmetic test counting fake-GitHub calls; contract tests (Schemathesis against the binary, response validation in `apitest`); archtest.
- Tests assert, run offline (a network-less CI job), never depend on the working directory (`t.TempDir`), and `t.Skip` needs an issue link.
- CI runs `go test -race` with cgo enabled; the release build is `CGO_ENABLED=0`; the race detector exercises the pure-Go SQLite driver.
- Fixtures are recorded against the fake GitHub by the regeneration script (Q-21).

## Alternatives considered
Mocks generated by tools (hand-written fakes named after behaviour are clearer), live-GitHub integration tests (flaky, budget).

## Consequences
The fake GitHub is a maintained artefact; recorded fixtures need a documented regeneration script.

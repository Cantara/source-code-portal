# Content: docs, commits, badges
Status: as built. Binding order: ../plan.md > this note.

## Scope
- `internal/docs`: README and `docs/**` Markdown rendered to `SafeHTML` with a table of contents; raw source kept for `internal/llms`;
  the image proxy (images-events.md).
- `internal/safehtml`: the `SafeHTML` type and the single sanitiser policy.
- `internal/commits`: the latest 30 default-branch commits per repository and `GET /api/v1/commits` over the merged feeds.
- `internal/badges`: local flat SVG badges `last-commit`, `release`, `license`, `issues` per repository and `repos` per group; the
  latest-release job.
- The `scp.yaml` descriptor is owned by `catalog.md`.

## Decisions
- Images (relative and absolute `https`) are rewritten to the image proxy, `/images/{owner}/{name}/{id}`, and recorded with the document
  (images-events.md); the sanitiser admits only that `src` form.
- The page CSP allows images from `'self'` (http-api.md); `<img>` gets `referrerpolicy="no-referrer"` and `loading="lazy"`.
- Non-Markdown READMEs (`.adoc`, `.rst`, `.txt`, extensionless text) render as escaped text (`safehtml.Text`): every README shows something.
- Mermaid fences render as code blocks (`<pre class="chroma"><code class="language-mermaid">`, not highlighted).
- goldmark with `html.WithUnsafe` (raw `<details>`, `<img>`, `<kbd>`, `<sub>` are common in READMEs); sanitising after rendering is
  therefore mandatory.
- chroma v2 with `WithClasses(true)`: highlighting is classes only, so the CSP keeps styles to `'self'`; the theme CSS is generated by
  `internal/docs/chromacss` into `web/src/styles/chroma.css`.
- bluemonday behind `safehtml.Policy.Sanitize`; `Sanitize` and `Text` are the only constructors of `SafeHTML`: the type proves sanitisation.
- Stored HTML is untrusted bytes; it is sanitised again at publish: the cache cannot inject script.
- Heading and author ids are prefixed `doc-`; `name` attributes are removed: document ids stay apart from the page's own.
- `pipelineVersion` (2) and `safehtml.PolicyVersion` (2) are stored with every document; a different value renders the stored source
  again. `TestPipelineLock` fails until the version is bumped when output changes.
- A linear shape guard runs before goldmark (nesting 64, one inline stream 40 KiB, sum of squared stream lengths 2e9); a document that
  fails it renders as text: rendering time stays linear in input size.
- Highlighting runs for blocks up to 4 KiB and within 1.5 s per document: time stays bounded on crafted input.
- Front matter: four keys (`title`, `description`, `order`, `hidden`) are read; the README is rendered whole, as GitHub does.
- Commit, release, licence and issue facts live in `internal/snapshot` value types; `badges` reads the snapshot.
- `issues` shows GitHub's `open_issues_count` (includes pull requests): it comes with the listing.
- `release` reads `/releases/latest` (published, non-prerelease): one call, GitHub's own definition of "latest".
- Badge text widths come from a committed Go table in `internal/badges/widths.go` (DejaVu Sans), plus `textLength`.
- Badge ETag is a hash of the body: `last commit: today` turns `yesterday` at 00:00 UTC without a data change.
- One palette, WCAG AA contrast.

## Shapes
```go
// internal/safehtml
type SafeHTML struct{ s string }                       // zero value = empty; String() for DTOs
func New() *Policy                                     // the one policy, shared
func (p *Policy) Sanitize(b []byte) (SafeHTML, error)  // only constructor from HTML; input cap 8 MiB
func Text(s string) SafeHTML                           // escaped text in one <pre>
const PolicyVersion = 2

// internal/snapshot (shared value types)
type Commit struct{ SHA, Subject, AuthorName, AuthorLogin, URL string; CommittedAt time.Time }
type CommitRef struct{ Repo RepoKey; Commit *Commit }
type Release struct{ Tag, Name, URL string; Published time.Time }
type Doc struct {
    Path string; README bool; Title, Description string; Order int; Hidden bool; Format string // markdown | text
    HTML safehtml.SafeHTML; Source []byte; TOC []Heading; BlobSHA string
    Truncated bool; State State; Images []Image                // State: ok | too_large | unsupported
}
type Heading struct{ Level int; ID, Text string }   // h2 and h3 only
```
Per repository the snapshot holds `Commits` (newest first, at most 30), `Docs` (README first, then by `order`, then path) and `Release`,
each with its freshness (sync-snapshot-store.md). The merged feeds are `Latest` and one per group (`Feed`).

## Behaviour
### Docs
1. Job `docs` per repository: TTL 1 h, plus `EventPush`; unchanged blob SHAs cost no fetch. An empty repository is `no_content`, a
   repository without README or documents `not_found`.
2. README from the tree, as GitHub resolves it: `.github/`, then the root, then `docs/`; in one directory `README.md` first, then by name.
3. Docs: blobs under `docs/` (recursive) with extension `.md` or `.markdown` (case-insensitive), the first 50 in path order; a file equal
   to the resolved README is listed once; front matter `hidden: true` leaves it out of the list (display, not access control).
4. Format by path: `.md`/`.markdown` Markdown; an extensionless README is Markdown when its first 4 KiB starts with `#` or contains a
   fence, `](` or a list marker; anything else is text.
5. Size: a blob over 1 MiB is `too_large` and not fetched; over 512 KiB renders the first bytes cut at a line boundary with
   `Truncated: true`.
6. Encoding: BOM stripped; UTF-16 or NUL-dense input is `unsupported`; other invalid UTF-8 replaced with U+FFFD.
7. Pipeline, fixed order (`render.go`): decode -> truncate -> split front matter (16 KiB cap, one mapping, no anchors, aliases or merge
   keys) -> shape guard -> goldmark (GFM: tables, task lists, strikethrough, autolinks; footnotes; automatic heading ids; alerts
   `[!NOTE|TIP|IMPORTANT|WARNING|CAUTION]` as `md-alert md-alert-<kind>` with `p.md-alert-title`; chroma for fenced code) -> rewrite of
   links, images and ids on the HTML -> sanitise (last).
8. Heading ids: goldmark's automatic ids or the author's, then the `doc-` prefix; fragment links `#x` become `#doc-x`.
9. Links: relative paths resolve against the document's directory (leading `/` is repository-relative; a path above the root keeps only
   the text); an indexed document becomes its portal route `/repos/{owner}/{name}/docs/{path without extension}`; any other path
   `{web}/{owner}/{name}/blob/HEAD/{path}` (`/tree/` for a trailing slash). Schemes `http`, `https`, `mailto`. External links get
   `rel="noopener noreferrer nofollow ugc"`.
10. Images: relative path or absolute `https` URL -> `/images/{owner}/{name}/{id}` (images-events.md); any other source keeps the alt text
    as text; `srcset`, `<picture>` and `<source>` are dropped; `alt` always present.
11. Code: `<pre class="chroma"><code class="language-x">`, language must match `^[A-Za-z0-9_+#.-]{1,32}$` (else plain `<pre><code>`);
    budgets per Decisions.
12. Sanitiser policy (`safehtml.New`), built from an empty bluemonday policy:
    - Elements: text and structure (`p`, headings, lists, tables, `blockquote`, `pre`, `code`, `details`/`summary`, `kbd`, `sub`, `sup`,
      `div`, `span`, `section`, `figure`, ...), `a`, `img`, `input[type=checkbox]` with `checked`/`disabled`.
    - `id`: `^doc-[A-Za-z0-9_:.-]{1,100}$`; `class`: allow-list (chroma token classes, `language-*`, `md-alert*`, `footnote*`,
      `task-list-item`); `align` on `div`, `p`, `td`, `th`, `img`, `h1`..`h3`; `img` `width`/`height`, `loading=lazy`,
      `referrerpolicy=no-referrer`; `role` on footnote elements.
    - URLs: `http`, `https`, `mailto` or relative for `href`; `src` only the image proxy form.
    - Removed with content: `script`, `style`, `iframe`, `object`, `embed`, `svg`, `math`, `form`, `textarea`, `select`, `button`,
      `noscript`, `template`, `audio`, `video`, `canvas`; every other element and attribute is removed.
13. TOC: h2 and h3 of the rendered document (id, text capped at 120 runes), in order; served in the doc API and rendered by the web UI.
14. Title: front matter `title`, else first H1 text, else file name (120 runes); description: front matter, else the first paragraph
    (300 runes).
15. Raw source (after truncation) is stored in `Doc.Source`; `internal/llms` serves it cleaned (`untrusted.Strip`, comments removed).
16. Failure: a GitHub error keeps the previous documents and marks them stale; a render error renders the document as text.

### Commits
1. Job `commits` per repository: TTL 2 h (safety net), plus `EventPush`.
2. One request: list commits on the default branch, `per_page = 30`. An empty repository is `no_content`.
3. Per commit: SHA lower-case hex 40 or 64 (else dropped); first line of the message cleaned with `untrusted.Text`, capped at 200 runes;
   author name capped at 100 runes; author login when it matches GitHub login syntax (else empty); committed date UTC whole seconds, a
   missing date drops the commit, a date more than 24 h ahead is clamped to when the commit was first seen; URL only when `https`;
   parents (from the same listing, no extra request) lower-case, valid SHAs only, duplicates dropped, at most 8, first parent first.
   The payload schema is 2.
4. Order newest first by `(committedAt desc, sha desc)`; duplicates by SHA dropped.
5. Storage: the commits are the item's payload, replaced on each successful run; a removed repository's item cascades.
6. Aggregation at snapshot build: `Latest` merges every repository's commits, and each group has its own merged feed; a repository in
   several groups appears in each group feed.
7. API `GET /api/v1/commits?group=&repo=&automation=&page=&limit=` (`repo` is `owner/name`): `limit` 1..200 (default 50), `page`
   1..100000; numbered pages are slices of the feed in order `(committedAt desc, repo asc, sha desc)` with `{number, size, total, pages}`;
   `repo` and `group` intersect.
8. Freshness of a page: the repository's own when `repo` is set; else `fresh` only when the commits of every repository in scope are
   fresh, `unknown` for an empty scope, otherwise `stale`.
9. Day grouping happens in the web UI in the viewer's time zone; the server returns UTC.

### Badges
1. Routes: `GET /badges/repos/{owner}/{name}/{kind}.svg` (`last-commit`, `release`, `license`, `issues`, `health`) and
   `GET /badges/groups/{group}/{kind}.svg` (`repos`, `health`, `last-commit`, `release`; health.md).
2. Job `badges.release` per repository: TTL 24 h, plus `EventTag`; the latest release (`badges.FromGitHub`), 404 means "no release" (`not_found`).
3. Messages: `last-commit` `today`/`yesterday`/`N days ago` (2..13)/`N weeks ago`/`N months ago`/`N years ago` by UTC calendar days, green up
   to 90 days, blue to 365, amber beyond; `release` tag name; `license` SPDX id (`NOASSERTION`/`OTHER` -> `other`); `issues` `{n} open`
   (green at 0); `repos` member count. Counts: 0..999, then `1.2k`, `12k`, `1.2M` (truncated).
4. Unknown repository, kind or group: `404` grey `unknown`, `Cache-Control: public, max-age=60`, no ETag.
5. Known repository without data: `200` grey `unknown`; known absence (no release, no licence, no commits): `200` grey `none`; both `max-age=60`.
6. Data badge: `200`, `Cache-Control: public, max-age=300`, strong ETag of the body, `304` on match.
7. No catalogue yet: `503` grey `starting`, `Retry-After: 15`, `no-store`.
8. Every response: `Content-Type: image/svg+xml`, `Content-Security-Policy: default-src 'none'; sandbox`,
   `Cross-Origin-Resource-Policy: cross-origin`, plus the common security headers. Owner and name match case-insensitively; an old address
   serves through the alias map.
9. Rendering: typed structs through `encoding/xml`; elements `svg`, `title`, `g`, `rect`, `text`; height 20, 5 px padding, label and
   message cleaned and capped at 40 runes; characters illegal in XML 1.0 become U+FFFD; `role="img"`, `aria-label` and `<title>` =
   `label: message`; white text; palette label `#555555`, success `#1a7f37`, info `#0b61a4`, warning `#b45309`, neutral `#6e6e6e` (all >= 4.5:1).
10. Width: sum of the table's advances (font units per em 2048; outside the table 1271, wide characters 2048) at 11 px; `textLength`
    fixes the drawn length for any viewer font.

## Config
No keys: the limits (50 documents, 1 MiB per file, 512 KiB rendered, 30 commits, the badge cache ages) are constants in `internal/docs`,
`internal/commits` and `internal/badges`.
